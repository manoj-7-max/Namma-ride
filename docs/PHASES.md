# Phases

1. **Foundation (complete):** monorepo, API, PostgreSQL, migrations and CI.
2. **Authentication and booking (complete):** test OTP/JWT roles, caps, approval, fare estimate and lifecycle.
3. **Live pilot dispatch (current):** foreground fixes, nearby matching, timed offers/retries, row-locked acceptance, persisted events, SSE/polling, maps, live operations and automated debug APK artifacts.
4. **Operational hardening:** production SMS/push, consent/audit policy, managed map/routing provider, geographic service boundary, HTTPS deployment, backups, observability, emergency support, load/field testing and production signing.

Phase 3 is private test software. Payments and public ride operations remain disabled; Bike Taxi is demo-only.
